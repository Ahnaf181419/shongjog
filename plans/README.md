# Implementation Plans — Shongjog improvement program

Generated by the improve skill on 2026-08-22, planned at commit `a1b42a6`.
Three phases, executed in order: **C (safety nets) → B (real app defects) → A (new learner value)**.

## Repo facts every executor must know (not visible from git alone)

1. `site/` (the deployed teaching site) is **gitignored by design**. Git-based drift checks
   do not work on it. Drift check for site files = open the "Current state" excerpt
   locations and compare; STOP on mismatch.
2. Standing operator rule: **never commit or push anything without explicit permission**.
   Teaching files under `site/` are never committed. App files (`lib/`, `test/`, `tools/`,
   `assets/`, `eval/`) are tracked — commit only if the operator instructs.
3. Deploy flow: the site ships as a zip (`shongjog-site-v2.zip` at repo root) manually
   dropped into Netlify. After any `site/` change, run `predeploy.sh` (plan 002) and tell
   the operator to redeploy once.
4. `site/LESSON-SPEC.md` is the binding content spec for lessons (quiz rules, skeleton,
   kicker format). Read it before editing any lesson.
5. Live site: https://shongjog-lesson-guide.netlify.app/
