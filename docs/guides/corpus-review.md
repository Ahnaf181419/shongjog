## Review Process

1. Reviewer receives the corpus JSON (printed or shared digitally)
2. For each chunk, reviewer checks:
   - **Accuracy:** Is the guidance correct per current WHO/BDRCS standards?
   - **Completeness:** Are critical steps missing?
   - **Language:** Is the Bangla clear and appropriate for low-literacy users?
   - **Safety:** Could any instruction cause harm if followed incorrectly?
3. Reviewer marks each chunk: ✅ Approved / ⚠️ Revise / ❌ Remove
4. Team implements revisions, reviewer re-checks revised chunks
